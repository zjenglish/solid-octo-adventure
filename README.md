# Fenway Boys Soccer - Fall 2026

A comprehensive soccer program management system for Fenway High's three-school co-op (Fenway, Josiah Quincy, Snowden).

## Contents

### Presentations
- **SOCCER_MEETING_SLIDESHOW.html** - Interactive 15-slide presentation for student/parent information meeting
  - Season overview, eligibility requirements, schedule, coaching staff
  - Soccer-themed design with pitch background
  - Open with any web browser

### Dashboards
- **ELIGIBILITY_DASHBOARD.html** - Real-time roster eligibility tracker
  - Shows eligible students, missing consent, missing physicals
  - Color-coded status indicators
  - Live HTML dashboard

### Trackers
- **ROSTER_ELIGIBILITY_TRACKER.csv** - Spreadsheet format for tracking student eligibility
  - Import into Google Sheets, Excel, or any spreadsheet tool
  - Track physical exams, consent forms, overall status

### Documentation
- **docs/SOCCER_HUB.md** - Master repository with all program info
  - Schedule, roster, contacts, compliance requirements
  - Eligibility checklist, coaching staff details

## Program Structure

Three-school co-op serving:
- Fenway High School
- Josiah Quincy Upper Academy
- Snowden High School

**Core Principle:** Everyone who tries out makes the team (Varsity or JV)

- Varsity: 16-18 players
- JV: 12-15 players
- Total: ~30-35 players
